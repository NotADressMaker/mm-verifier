# About MAMV

MAMV helps people see how an AI answer was checked. The user problem is simple: AI answers can be wrong, unsupported, or hard to audit after they are copied into products, reports, workflows, or decisions.

MAMV is an open-source AI verification platform. A user submits an AI output or claim, MAMV runs configured verification checks, and MAMV returns a portable trust receipt that records what was reviewed, what the system concluded, what evidence or votes supported the result, and how someone can verify the receipt later.

MAMV does not prove truth. It produces an audit trail for a verification process. For higher-stakes cases, receipt hashes can optionally be anchored onchain to make the receipt tamper-evident. Onchain anchoring proves the record has not changed since anchoring; it does not prove the AI answer is correct.

Longer term, MAMV is designed to support a decentralized verifier marketplace with provider reputation and dispute mechanisms. That marketplace is roadmap work, not required for the MVP.
